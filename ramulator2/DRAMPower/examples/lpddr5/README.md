# LPDDR5 example power profile

`lpddr5_16gb_x16_6400_estimated.json` matches Ramulator's
`LPDDR5_16Gb_x16` / `LPDDR5_6400` organization and timing. Electrical and
impedance values are inherited from the public DRAMPower LPDDR5 test profile;
they are suitable for integration and comparative experiments, not absolute
vendor-silicon validation.
